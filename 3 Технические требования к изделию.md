
[[0. ТЗ Главная]]
# 3.1 Состав изделия

**Клиентские приложения:**
- NoteTime для Windows (10/11)
- NoteTime для macOS (12+)
- NoteTime для Linux (Ubuntu 20.04+, Astra Linux, Alt Linux)
- NoteTime Mobile для iOS (15+) — опционально
- NoteTime Mobile для Android (10+) — опционально

**Компоненты:**
- Модуль работы с Vault Obsidian
- Модуль временных меток
- Модуль Markdown-редактора
- Модуль YAML frontmatter
- Модуль поиска и фильтрации
- Модуль синхронизации (опционально)
- Модуль экспорта/импорта
- Модуль резервного копирования

**Серверная часть (опционально):**
- API синхронизации
- База данных метаданных
- Сервис аутентификации
# 3.2 Требования назначения

 Основные функции
- [ ] Создание заметки с временной меткой
- [ ] YAML frontmatter: `created`, `modified`, `tags`, `type`, `time`, `duration`
- [ ] Интеграция с Obsidian Vault
- [ ] Markdown-редактор
- [ ] Хронологический просмотр
- [ ] Фильтрация по времени
- [ ] Поиск
- [ ] Ежедневные заметки (Daily Notes)
- [ ] Тайм-трекинг
- [ ] Экспорт (PDF, DOCX, HTML, Markdown)
- [ ] Импорт (Obsidian, Evernote, Notion, Joplin)
- [ ] Резервное копирование

**Интеграция с Obsidian Vault:**
- чтение структуры папок
- создание/редактирование/удаление `.md` файлов
- поддержка тегов `#tag`
- соблюдение структуры Vault

**Требования к производительности:**

| Параметр              | Значение                |
| --------------------- | ----------------------- |
| Время запуска         | ≤ 2 с                   |
| Время отклика         | ≤ 0,3 с                 |
| Время сохранения      | ≤ 0,2 с                 |
| Vault 10 000+ заметок | без зависаний           |
| Полнотекстовый поиск  | ≤ 1 с на 10 000 заметок |
# 3.3 Конструктивные требования

**Аппаратные требования:**

| Параметр | Минимум | Рекомендуется |
|---|---|---|
| ОС | Windows 10, macOS 12, Ubuntu 20.04 | Windows 11, macOS 14, Astra Linux |
| Процессор | 2 ядра, 2 ГГц | 4 ядра, 3 ГГц |
| ОЗУ | 4 ГБ | 8 ГБ |
| ПЗУ | 500 МБ | 2 ГБ |
| Экран | 1280×720 | 1920×1080+ |

**Архитектура:**
- Модульная архитектура
- Кроссплатформенность (Electron, Tauri, Qt или аналог)
- Локальное хранилище (SQLite + файлы Markdown)
- Отсутствие жёсткой привязки к облаку

**Совместимость:**
- Windows 10/11
- macOS 12+
- Linux (Ubuntu, Astra, Alt)
- Obsidian 1.12+

# 3.4 Требования электромагнитной совместимости

Приложение не работает с радиочастотным оборудованием.
# 3.5 Требования живучести и стойкости
- Сохранение работоспособности без интернета (полный офлайн)
- Восстановление после сбоя питания
- Устойчивость к повреждению файлов Vault
- Автоматическое резервное копирование
- Устойчивость к климатическим условиям эксплуатации устройства
- Устойчивость к механическим нагрузкам

# 3.6 Требования надежности

| Показатель                               | Значение       |
| ---------------------------------------- | -------------- |
| Коэффициент готовности                   | ≥ 0,99         |
| Средняя наработка на отказ               | ≥ 10 000 часов |
| Назначенный ресурс                       | 5 лет          |
| Срок службы                              | 5 лет          |
| Срок хранения                            | 3 года         |
| Вероятность безотказной работы за 1000 ч | ≥ 0,98         |

- Обязательное резервное копирование
- Методы оценки: расчётно-экспериментальный и экспериментальный
# 3.7 Требования эргономики и технической эстетики

 Интуитивно понятный интерфейс (≤ 3 уровней вложенности)
 Время освоения — ≤ 15 минут
 Контрастность и шрифт — WCAG 2.1 AA
 Поддержка экранных читалок (NVDA, VoiceOver)
 Тёмная и светлая темы
 Настраиваемые горячие клавиши
 Модульная раскладка панелей
 Единый стиль, адаптация под бренд
# 3.8 Требования к эксплуатации, хранению, ТО и ремонту
 **Рабочие условия:** Windows 10+, macOS 12+, Linux
 **Предельные условия:** офлайн до 365 дней
 **Продолжительность непрерывной работы:** не ограничена
 **Аварийные ситуации:** сохранение локальных данных при сбое
 **Объективный контроль:** логирование ошибок, отчёты о сбоях
 **Обслуживающий персонал:** 1 администратор, 1 разработчик поддержки
 **Виды ТО:** обновление раз в квартал, по техническому состоянию
 **Обновление:** автоматическое
 **Состав инструментов:** встроенные средства диагностики, удалённый доступ
 **ЗИП:** резервные копии, тестовые устройства
 **Условия хранения:** локальное и облачное хранилище
 **Сроки хранения данных:** 5 лет
 **Трудоёмкость ТО:** ≤ 4 часов в месяц
# 3.9 Транспортирование

- Класс опасности: не опасен
- Виды транспорта: не применяется (цифровой продукт)
- Передача: HTTPS, TLS 1.3, физический носитель
- Подготовка: дистрибутив, подпись кода, checksum
- Приведение в рабочее состояние: установка инсталлятора
# 3.10 Требования безопасности
Безопасность:
- Защита от НСД: двухфакторная аутентификация, шифрование (AES-256)
- Биометрическая блокировка (Face ID, Touch ID, Windows Hello)
- Критерии опасного состояния: утечка данных, сбой синхронизации
- Соответствие: 152-ФЗ, GDPR
- Утилизация: удаление аккаунта и всех данных
