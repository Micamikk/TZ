
## Приложение 1. Схема интеграции с Obsidian

```mermaid
flowchart LR
    subgraph NoteTime
        A[Markdown-редактор]
        B[Модуль временных меток]
        C[Модуль YAML]
        D[Поиск и фильтрация]
    end
    subgraph Obsidian Vault
        E[Папка Vault]
        F[.md файлы]
        G[Вложения]
    end
    A --> E
    B --> F
    C --> F
    D --> F
    E --> F
    E --> G
```

## Приложение 2. Пример YAML frontmatter

```yaml
---
title: Заметка NoteTime
created: 2026-09-21T14:30:00
modified: 2026-09-21T15:45:00
type: note
tags: [notetime, заметки, хронология]
time: 14:30
duration: 75
---
```

## Приложение 4. Сценарий создания заметки

```mermaid
sequenceDiagram
    participant П as Пользователь
    participant NT as NoteTime
    participant V as Obsidian Vault
    П->>NT: Создать заметку
    NT->>NT: Добавить timestamp
    NT->>NT: Сформировать YAML
    NT->>V: Сохранить .md файл
    V-->>NT: OK
    NT-->>П: Заметка создана
    П->>NT: Открыть в Obsidian
    NT->>V: Передать файл
    V-->>П: Отображение заметки
```

## Приложение 5. Сценарий синхронизации

```mermaid
sequenceDiagram
    participant NT as NoteTime
    participant FS as Файловая система
    participant OBS as Obsidian
    NT->>FS: Запись .md
    FS-->>NT: OK
    OBS->>FS: Чтение .md
    FS-->>OBS: Контент
    OBS-->>OBS: Обновление индекса
    Note over NT,OBS: Vault синхронизирован
```
